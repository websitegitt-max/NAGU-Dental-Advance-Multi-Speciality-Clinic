# NAGU Dental Multi Speciality Website Template

A responsive dental clinic website template built with React, Vite, and Tailwind CSS.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production Build

```bash
npm run build
npm run preview
```

## Features

- Appointment bag with local persistence
- WhatsApp cancellation flow
- Treatment and gallery sections
- Image lightbox
- Editable clinic configuration
